# Artwork

The indoor house, furniture and residents are drawn by project code in
`src/house/HouseCanvas.tsx`, with layout/collision data in `data/house.ts`.
`public/house.svg` is project artwork. These additions use the MIT license.

Unused AI Town raster tiles, sprite sheets, music, fonts, favicon, UI artwork
and editor assets are excluded: their redistribution terms were not independently
established. Legacy source modules remain for attribution/compatibility, but the
active house entry point does not load those assets. The upstream level editor
is not included or supported by this release. Simple top-level SVG icons come
from AI Town source under its MIT notice; no upstream pixel GUI pack is bundled.

The README screenshot must come from a fresh, free local database and contain
no owner credentials or private chat. Do not substitute a running personal screenshot.
